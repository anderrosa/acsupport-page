# ACSUPPORT

Site institucional da ACSUPPORT. Landing page com serviços, apresentação da empresa e contato.

Site no ar: [https://acsupport.com.br/](https://acsupport.com.br/)

## Stack

React, TypeScript e Vite, com Tailwind CSS.

## Como rodar

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Preencha o `.env` com e-mail, WhatsApp, Instagram e LinkedIn. Esse arquivo fica de fora do Git.
